Claude Code 설치하기
1단계 — 터미널 열기

맥에서 '터미널'은 컴퓨터에게 글자로 명령을 내리는 앱입니다.

⌘ Command + Space → 터미널 입력 → Enter

2단계 — Claude Code 설치
$ curl -fsSL https://claude.ai/install.sh | bash
3단계 — 실행 + 로그인
$ claude

브라우저가 열리면 Claude 계정으로 로그인해주세요.

✓ 성공 화면
🐷 Claude Code v2.x.x Sonnet 4.6 (200k context) · Claude Pro /Users/me ❯ ▊
1단계 — PowerShell 열기

윈도우에서 'PowerShell'은 컴퓨터에게 글자로 명령을 내리는 앱입니다.

⊞ Win 키 → PowerShell 입력 → Enter

⚠️ '명령 프롬프트(cmd)'가 아닌 'PowerShell'을 열어주세요

2단계 — Git 설치 확인
PS> git --version

버전 숫자가 뜨면 OK. 오류가 나면 git-scm.com에서 설치 후 진행해주세요.

3단계 — Claude Code 설치
PS> irm https://claude.ai/install.ps1 | iex
4단계 — 실행 + 로그인
PS> claude

브라우저가 열리면 Claude 계정으로 로그인해주세요.

✓ 성공 화면
🐷 Claude Code v2.x.x Sonnet 4.6 (200k context) · Claude Pro C:\Users\me ❯ ▊
설치가 안 될 때: ChatGPT나 Claude에게 에러 메시지를 그대로 붙여넣으면 대부분 해결됩니다.
