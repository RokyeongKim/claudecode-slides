왜 마크다운인가?

PDF 그대로 → 표 깨짐, 이미지 텍스트 누락 가능
마크다운 변환 → AI가 구조를 정확히 인식
같은 내용도 토큰 절약 (= 더 많이 처리 가능)

실전 팁: 중요한 PDF는 마크다운으로 변환해서 AI에게 주면 정확도가 올라갑니다.

GitHub, Notion, Obsidian 등 대부분의 생산성 도구가 마크다운 기본 지원

3 MCP — 외부 도구 연결

MCP(Model Context Protocol) = AI와 외부 도구를 연결하는 표준 규격

비유: USB-C처럼, 하나의 규격으로 모든 도구를 연결
연결한 도구실제 활용
Notion매일 to-do 관리, 노트 정리, 프로젝트 트래킹
Fireflies회의록 자동 녹취 → Obsidian에 마크다운으로 저장
Google Calendar"오늘 일정 알려줘" → 멀티 계정 통합 조회
Gmail"지난주 OO에게서 온 메일 찾아줘" → 검색 + 요약

MCP 연결 방법 — 처음에는 이것만

방법난이도설명
Connector★☆☆이거부터 — claude.ai/settings/connectors 에서 클릭
claude mcp add★★☆터미널 명령어로 직접 등록
Plugin★★★/plugin → 탐색(Discover) + 클릭으로 설치

Plugin = MCP + 스킬 + 설정을 묶은 패키지. /plugin으로 탐색하고 한 번에 설치.
